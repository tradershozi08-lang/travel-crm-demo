# Security & Public Demo Boundary

This repository is intentionally safe for public viewing.

## Not included
- real customers or passengers;
- production database files or exports;
- passwords, tokens or API keys;
- `.env` files;
- payment-provider credentials;
- bank account information;
- WhatsApp or Telnyx secrets;
- call recordings;
- employee private assets;
- production documents or uploads;
- proprietary production backend code.

## Demo data
Every person, booking, payment, message and amount shown in the demo is fictional or illustrative.

## Reporting a concern
If you believe sensitive information has accidentally been committed, please report it privately to the repository owner rather than opening a public issue with the sensitive value.
